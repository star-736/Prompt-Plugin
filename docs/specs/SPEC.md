# FutureContext 当前产品规格

本文合并原一期至四期中仍适用的规则，并纳入新标签页阅读、目录投递与可选同步。它描述当前代码的产品行为，不把早期设想当作已实现功能。

术语见 [CONTEXT](../CONTEXT.md)，配置步骤见[配置指南](../CONFIGURATION.md)，阶段变化见[历史](./HISTORY.md)。同步的格式、合并与调度细节集中在[同步技术规格](./SPEC_GITHUB_SYNC.md)。

## 产品范围

- Edge / Chrome Manifest V3 扩展，本地优先，无账号或自有后端。
- 工具栏弹窗完成资产管理，也可在新标签页打开同一工作区；不使用浏览器侧边栏。
- 四类资产：通用 Prompt、Skill、AIGC Prompt、指令。只有 AIGC 可存入私密库。
- AI 整理、GitHub 收集、普通库同步与网页取用均为用户选择的功能，相关站点访问按操作授权。

## 资产与编辑

| 资产 | 编辑内容 | 列表呈现 | AI 整理 |
| --- | --- | --- | --- |
| 通用 Prompt | 可选标题、必填正文、分类 | 标题；无标题显示正文摘要 | 可补标题、归类 |
| 单文件 Skill | 完整原始 `SKILL.md`、分类 | YAML `name` 与 `description` | 可归类，不改写 YAML |
| GitHub 包式 Skill | 来源包只读，管理分类、更新与投递 | 同上，提供文件树与阅读 | 可归类 |
| AIGC（普通 / 私密） | 仅必填正文 | 正文前两行，超出省略 | 不处理 |
| 指令 | 必填多行正文、分类；无标题 | 等宽正文前两行与分类 | 不处理 |

- Skill 保存时校验 YAML frontmatter 的 `name` 与 `description`，不通过额外标题表单改写主文件。
- 早期 AIGC 标题与分类数据保留以兼容旧库和备份，当前界面不显示、编辑或筛选这些字段。
- 新资料库仅预设“终端指令”“浏览器指令”两个指令分类，不预置资产。既有资料库不补入预设，删除或重命名后也不恢复。
- 新条目默认未分类；在分类筛选下创建时预选该分类。编辑页可新建分类并继续当前草稿。
- 内容不设标签、模型参数、正负提示词字段或示例资产。

## 工作区、分类与排序

- 首次打开进入通用 Prompt，以后记住最近的普通页签；顺序为通用 Prompt、Skill、AIGC Prompt、指令。
- AIGC 内切换普通 / 私密库，私密库不自动进入。搜索只作用于当前页签与库，私密内容仅解锁后可搜索。
- 通用 Prompt、Skill、指令各自维护一级分类，支持新建、重命名与删除；删除分类只把条目移到未分类，确认时显示受影响数量。
- 普通列表支持最近编辑、最近取用、最常取用，按页签记住选择。置顶优先，置顶之间按所选顺序排列；私密库只按最近编辑，不支持置顶。
- 显式复制和成功就地取用计入本地取用次数与时间，不改变编辑时间或触发 AI 整理。设置页提供本周、近 30 天和累计概览。
- 无内容时仅显示相应“暂无…”与新建入口，不预置教学内容。
- 界面为暖白、浅灰与雾蓝，私密区域用浅薰衣草与细线锁图标；指令激活页签用低饱和绿色。Logo 为开口向右的圆角 C，工具栏使用打包的 PNG 图标。

## 草稿与保存

- 输入自动保留本地草稿，关闭弹窗不打断；正式保存才创建或更新资产。
- 返回时若有未保存修改，提供继续编辑或放弃草稿。
- 正式保存与放弃前停止待写草稿，并等待正在执行的草稿；保存期间禁止重复提交，失败保留输入与可重试错误提示。
- 外部存储变化不能替换正在输入的表单、丢失焦点或光标；旧异步结果不能覆盖新编辑。
- 保存采用已确认快照；慢写入等待真实结果，不将仍执行的保存提前报失败。实现约束见 [ADR 0011](../adr/0011-serialize-database-writes-across-extension-contexts.md)。

## 私密库、复制与删除

- 私密库是可恢复的本地访问锁，不抵御拥有浏览器配置文件或本机账户访问权的人。
- 首次设置至少 6 位密码并确认；解锁仅当前工作区页面会话有效，关闭页面后重新锁定，锁定时隐藏数量与内容。
- 私密资产从已解锁私密库创建。普通与私密 AIGC 迁移需明确确认，提交成功后才移除原区域内容；移出后普通库可直接查看。
- 重设隐私锁保留所有资产，但清空无法再解密的 Provider 配置。
- 复制按用户明确操作写入剪贴板，不包含标题或分类。**Skill 复制与就地取用会在主文件前加“基于以下 skill 辅助我解决问题”一行**，主文件正文保持原样，不把前缀写回存储。
- 永久删除需要确认，没有回收站。删除库内收藏不等于撤回 Agent 目录副本。
- 确认标题使用操作短语，危险按钮使用具体动词；私密迁移与删除放在详情或编辑页。

## GitHub Skill 与阅读

- 仅从用户主动打开的公开 GitHub 具体 `SKILL.md` 文件页收集，不从仓库首页扫描，不自动更新。
- 主文件位于子目录时收集该目录的递归文件；位于仓库根目录时收集根文件及 `scripts/`、`references/`、`assets/`，不会收集所有其它子目录。
- 记录仓库、目录和精确 Commit。包大小上限 10 MiB，单文件上限 5 MiB；超限整体拒绝，脚本与二进制仅保存，不执行。
- 相同仓库、路径与 Commit 的再次收集不创建副本。手动检查来源默认分支下同路径的更新，更新替换包并保留分类与管理信息。
- 单文件 Skill 可原始编辑，GitHub 包通过“管理 Skill”处理；包文件支持文本查看，二进制显示名称和大小。
- 新标签页默认渲染根 `SKILL.md`，单独展示名称与描述；宽屏文件树在右侧，窄屏在正文上方并默认收起，包内 Markdown 链接可打开已保存文件。
- Markdown 使用随扩展打包的依赖并消毒，不从 CDN 加载，资源访问受限制。

## 网页取用与就地保存

- 总开关与逐站启用共同控制取用，站点权限为可选授权；常见 AI 站点提供启用提示，其它 HTTPS 站点可手动添加。
- 只在启用站点加载页面脚本，停用或关闭功能时更新现有页面状态；只读取当前输入框的必要文字，不采集其他页面内容或网络。
- `//` 或默认快捷键 `Alt+Shift+F` 打开面板，触发符可关闭，实际快捷键可在浏览器扩展快捷键设置中修改。
- 面板最多 8 条，按置顶、匹配程度、取用次数和最近编辑排序，匹配标题、正文与分类名。
- 普通聊天页只取用通用 Prompt 与 Skill；`grok.com/imagine` 及子路径只取用普通 AIGC。按路径区分同源页面；私密内容与指令始终排除。
- ↑↓ 选择，Enter / Tab 或点击确认插入，Esc 关闭。插入替换触发符和搜索词，光标落在内容末尾，不自动发送；无法写入时退化为复制并提示粘贴。
- 右键“保存到 FutureContext”仅处理用户选中文字，保存为无标题、未分类的通用 Prompt，符合条件时进入 AI 队列；不打开编辑页。
- 空白或超过 100,000 字符的选区不保存；保存结果通过徽章与适用页面的轻提示反馈，不提供保存整段对话。

## 后台 AI 整理

- 用户可配置多个 Provider，但只选择一个当前服务。支持预设服务与自定义 OpenAI 兼容 Base URL，手填 Model ID，不自动拉取模型目录。
- API Key 以隐私锁密码加密本地保存，按浏览器会话解锁，与私密工作区页面解锁生命周期不同。凭据实现见 [ADR 0003](../adr/0003-encrypt-provider-keys-with-session-unlock.md)。
- 只处理符合规则、已保存的普通通用 Prompt 与 Skill，不发送私密内容、草稿、AIGC 或指令。新建及正文实质修改后入队，不阻塞保存，不自动回扫历史内容。
- 人工标题与分类优先；只有用户主动执行“整理现有内容”时才把历史资产加入队列。
- 未手动分类的内容可归入已有分类或达到阈值后创建分类，默认未分类阈值为 7 条。
- 已有分类的重命名、合并或拆分仅生成建议，用户可调整、应用或保留原结构；结构检查默认新增 / 编辑 7 条且间隔 14 天。
- 配置、队列、内容或会话变化后旧响应不得继续应用；失败通过设置状态反馈，不打断日常操作。完整操作历史与一键撤销尚未提供。

## Agent 投递

- 用户选择并授权 Agent 目录，扩展使用其中的 `skills` 子目录；绑定不会自动写入收藏。
- 已保存 Skill 按条明确投递，可更新投递、撤回。撤回只处理带归属标记且属于该资产的文件，库内收藏保留。
- 绑定后对照磁盘，用 YAML name 与同名目录判定已有 Skill，用主文件判断版本。Cursor / Codex 还可对照已绑定的通用 Agent 目录。
- 外来同名 Skill 显示“目录里已有”，不接管标记；用户确认“更新本地”可覆盖其内容，但撤回仍不删除它。
- 解除绑定保留磁盘副本；权限失效后需用户重新允许访问。相关理由见[投递设计](../adr/0008-explicit-skill-delivery-to-agent-directories.md)、[副本归属](../adr/0009-reconcile-bound-skill-directories-without-claiming-foreign-copies.md)与[版本判定](../adr/0010-match-local-skills-by-yaml-name-and-skill-md.md)。

## 备份、同步与兼容

- 完整备份为单个明文 JSON，含普通与私密资产和关联 Skill 文件；导出前解锁并明确提醒私密内容。导入不要求解锁，非破坏式合并，跳过重复条目，不把私密内容展示在库外。
- 备份保留资产取用字段，重复导入跳过时不合并次数，不导出凭据和本机目录授权。
- 可选 GitHub 同步仅合并普通库，不复用完整备份。配置、冲突、撤回、历史与容量规则以[同步技术规格](./SPEC_GITHUB_SYNC.md)为准。
- 数据与备份采用增量兼容，新字段补默认值，保留旧字段。遇到更新版本的资料库进入只读，不能用空库覆盖。见 [ADR 0006](../adr/0006-additive-schema-evolution-without-version-gating.md)。
- 资产 JSON 与 IndexedDB 文件包分别持久化；包准备、引用提交和清理通过同一写锁协调。中断后的无引用包可恢复清理，已引用包受保护，清理失败不误报保存失败。见 [ADR 0013](../adr/0013-recover-unreferenced-skill-packages-under-the-database-lock.md)。

这些功能可以在有实际需求时另行设计，不是必须完成的开发清单。
