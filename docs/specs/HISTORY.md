# 产品阶段历史

本文合并原一期至四期规格的背景与变化，只用于理解演进。当前规则见[产品规格](./SPEC.md)，配置步骤见[配置指南](../CONFIGURATION.md)；原始阶段文档的完整内容仍可从 Git 历史查看。

## 一期：建立本地资产库

目标是在 Edge 工具栏弹窗中保存、分类、编辑和显式复制通用 Prompt、单文件 Skill 与 AIGC，加入草稿、私密库和完整备份。

当时通用 Prompt 标题必填，普通 AIGC 有标题和分类，Skill 只支持主文件；界面限定弹窗、三页签和最近编辑排序，不包含网络整理、包式 Skill、网页取用、指令或同步。隐私锁选择可恢复设计，备份选择明文单文件，避免忘记密码导致资产不可恢复。

暖白、浅灰、雾蓝的视觉，以及开口向右的 C 字母品牌在这一阶段确定。早期提出过加密备份等方向，当前仍未提供。

## 二期：AI 整理与 GitHub Skill

用户自配 Provider 为通用 Prompt 补标题、为通用 Prompt 与 Skill 归类，加入按浏览器会话解锁的凭据保护；同时可从公开 GitHub 主动收集带精确 Commit 的 Skill 文件包，并手动检查更新。

通用 Prompt 标题改为可选；AIGC 界面改为只显示正文，旧标题和分类保留在数据中兼容。草稿与 AIGC 不发送给 AI，人工标题和分类优先，已有分类的结构修改需要用户应用。

当时仍强调全程弹窗、无同步、无页面代码。指令是后续加入的资产类型，原二期文档后来补入的指令说明不表示它在二期最初范围内。

## 三期：让已收藏内容更容易取用

只靠弹窗复制的操作路径较长，因此新增网页取用面板、选中文字右键保存、取用次数、常用排序与置顶。

页面代码逐站启用，用户确认后才插入，不自动发送；`//` 避开网站自带的单斜杠菜单。私密库不进入面板，取用统计保存在本地。新增字段采用增量兼容，更新版本数据只读，避免旧代码回退清空资料库。

当时仍无跨设备同步；变量填空、保存单条对话消息和面板内新建只是后续方向，未成为当前功能。

## 四期：独立的指令资产

为终端、CLI、AI Agent、浏览器指令和快捷键速查增加第四页签。指令以正文为标识、无标题、仅普通库，有独立分类，沿用草稿、搜索、复制、置顶与备份，不进入 AI 整理或网页取用面板。

随后统一界面名称为“指令”，内部类型保持兼容；新资料库预设“终端指令”“浏览器指令”分类，已有库与用户删除的分类不自动补回。

## 后续增量

- 新标签页工作区、Skill Markdown 阅读与可折叠文件树，扩展了原先“全程弹窗”的限制。
- Agent 目录绑定、明确投递与撤回，以及对外来同名 Skill 的识别；这些功能不是 GitHub 收集的自动副作用。
- 可选个人私有 GitHub 普通库同步，扩展了早期“无云同步”的限制；私密库和凭据仍不参与。见[同步规格](./SPEC_GITHUB_SYNC.md)与 [ADR 0012](../adr/0012-private-github-library-sync.md)。
- 跨上下文资料库写锁、草稿保存协调、旧 AI 响应保护与无引用 Skill 包恢复，完善日常可靠性。原因见[设计决策导航](../README.md)。

## 阅读历史时的常见差异

| 早期描述 | 当前状态 |
| --- | --- |
| 三类资产、通用 Prompt 标题必填 | 四类资产，通用 Prompt 标题可选 |
| AIGC 有标题和分类 | 界面仅正文，旧字段兼容保留 |
| 只支持单文件 Skill | 支持公开 GitHub 文件包，根目录收集有特定范围 |
| 全程弹窗、禁止网页插入 | 可打开新标签页，用户确认后可就地取用 |
| 无云同步 | 可选同步普通库到个人私有 GitHub 仓库 |
| Skill 复制与插入仅为主文件原文 | 当前取用文本在主文件前加一行引导语，存储原文不改 |
| Logo 以 SVG 实现 | 当前 manifest 使用打包的 PNG 图标 |
| 加密备份留待后续阶段 | 当前仍为明文备份，没有已完成承诺 |

ADR 保存当时选择方案的理由，阶段文字中的未来设想不等于当前实现或后续必做任务。
