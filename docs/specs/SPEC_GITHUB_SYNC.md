# GitHub 私有仓库同步技术规格

配置步骤和失败处理见[配置指南](../CONFIGURATION.md)，产品范围见[当前规格](./SPEC.md)，方案选择理由见 [ADR 0012](../adr/0012-private-github-library-sync.md)。本文集中维护同步格式、提交、合并与调度约束。

## 范围与边界

用户连接自己的已有个人私有仓库，不提供注册、托管服务器或公共仓库发布。设置包含仓库、专用细粒度 Token、启用、自动、立即同步、移除配置和状态。Token 只授予选定仓库 Contents 读写；与公开 Skill 收集 Token 独立，可信扩展存储保存，不回显、不导出。

同步所有普通 command/generic/skill/aigc 资产、普通分类与关联 Skill 包文件。同步白名单禁止私密资产/分类、草稿、锁密码、API Key、Token、Provider/会话配置、统计、skillDelivery、目录句柄。保留普通资产内容里用户主动写入的文本；白名单不是内容敏感词审查。

未提交的同步表单通过后台排队暂存在仅可信扩展上下文可访问的 `chrome.storage.session`，包含仓库、Token 草稿和开关。关闭弹窗后重新打开恢复设置页和输入，Token 草稿以密码框恢复，已配置 Token 不读回表单。暂存不是启用或保存配置，不进入资料库、同步文件或备份。保存成功、移除设置或主动放弃后清除；配置保存失败保留输入，暂存失败显示提示。浏览器重启或扩展重载、更新会清除会话暂存。设置页打开新标签页时保留设置视图，凭据不进入 URL。

## 数据与合并

远端固定文件 `.futurecontext/library.json`，格式 `futurecontext.library-sync` v1。记录键是 `asset:<稳定 ID>` 或 `category:<稳定 ID>`；值包含白名单资产或分类，或持久 `deleted:true` 标记。Skill 包嵌入关联资产，仅白名单 source 与相对路径/base64 文件数据。校验 ID、scope、隐私、类型、路径、防重复路径、实际文件尺寸、包限制、完整 source 和与正文一致的根 SKILL.md；无效远端文件整体拒绝，保持本地数据。

基线保存在本地数据库 `syncLedger`，按仓库隔离，包含上次确认的精确普通记录，永不导出。三方比较本地/远端/基线，首次连接两端合并。单方变化采用该版本；双向修改保留确定 ID 的冲突副本；删除与修改冲突保留删除及修改副本。分类冲突保留远端分类副本，并让远端资产引用该副本。设备取用和投递状态不随远端覆盖。

普通 AIGC 移入私密库维持原 ID，并在同一次本地保存持久记录仅含 ID 的撤回标记；之后删除私密条目或再次移出也保留标记，避免下一次同步前丢失撤回意图。若远端或基线存在该 ID，写 `deleted:true, withdrawn:true`，权威撤回同时阻止原 ID 及其普通冲突副本复活。未同步过的私密 ID 不生成远端记录。其它设备离线编辑与撤回冲突只在本地私密库保留编辑版本。私密资产不被远端覆盖。主动移回普通库获得新 ID，可以重新同步。Git 历史保留，不做历史改写或逐次迁移额外历史警告。

## 调度与失败

用户保存同步设置且启用时立即合并；立即同步按钮可手动触发。自动模式：相关持久变更后 7 秒防抖，30 秒持久报警补偿后台停止，5 分钟周期检查，工作区打开检查。浏览器/设备休眠可延后报警，界面不承诺精确时限。

网络请求限制到 8 秒，取消或配置变更时阻止旧配置继续上传/应用。上传前重新检查个人私有属性与当前数据库 revision，使用既有数据库写锁保护最后一次 revision 检查、上传及配置写入；最终合并通过 applyDatabaseChange 重新读取并应用，避免远端读取期间的本地编辑被覆盖。GitHub SHA 409/422 最多重读三次。错误可见且后续自动检查重试，离线编辑仍保存本地。任何已在服务器完成的提交仍保留普通 Git 历史。

## 限制

JSON 上限 15 MiB，含 Base64 文件与持久标记。读取大于 Contents 内联范围的文件改用 Git blob；超限保留本地并报告。`unlimitedStorage` 支持 IndexedDB 包、精确基线和本地资产存储。同步包采用新的不可变本地 ID，不覆盖原包，失败可能留下未引用包；删除标记不自动裁剪，以保护长期离线设备。恢复与清理规则见 [ADR 0013](../adr/0013-recover-unreferenced-skill-packages-under-the-database-lock.md)。

真实 GitHub 网络验收使用明确选择的测试配置与临时数据，模拟 API 测试不能代替真实服务验收；验证要求见[开发指南](../../AGENTS.md)。
