# 配置与使用指南

安装与功能概览见 [README](../README.md)。保存、搜索、编辑和复制普通本地资产无需配置下面这些功能；需要哪项，再阅读对应章节。完整行为规则见[当前产品规格](./specs/SPEC.md)。

## GitHub Skill 收集 Token

从公开 GitHub 仓库收集 Skill 可以匿名使用。Token 用于提高收集和检查更新时的请求额度，与私有仓库同步 Token 独立。

1. 打开扩展“设置 → GitHub Skill 收集 Token（可选）”。
2. 粘贴个人访问令牌，点击“保存 Token”。
3. 之后收集或检查更新时会使用该 Token；重新填写可替换，点击“移除 Token”恢复匿名请求。

保存只验证格式，不向 GitHub 发起请求，因此保存成功不代表令牌有效。过期、权限不足或限流会在实际收集、更新时提示；限流不会自动重试，有重试时间提示时可按提示稍后再试。

Token 明文保存在当前浏览器配置文件的扩展存储中，不在表单中回显，也不进入备份。它只发送到 GitHub API；能访问浏览器配置文件的人可以读取它。卸载扩展或清除扩展数据会删除本地 Token。

## GitHub 私有仓库同步

用于在设备之间同步普通库。需要自己已有的个人私有 GitHub 仓库，扩展不会替你创建仓库。

1. 准备专用细粒度 Token，仅授权目标仓库，赋予 Contents 读写权限；不要复用 Skill 收集 Token。
2. 打开“设置 → GitHub 私有仓库同步”，在“私有仓库”填写 `owner/repo`，在“同步 Token”粘贴专用 Token。
3. 勾选“启用同步”；需要自动同步时保留“自动同步”勾选。
4. 点击“保存设置”，按浏览器提示授予 GitHub API 访问权限。启用后会尝试首次同步，查看表单下方状态确认结果。

首次同步合并两端普通资产、分类和 Skill 文件，私密库、草稿、凭据与设备信息不参与；同步文件与字段规则见[同步技术规格](./specs/SPEC_GITHUB_SYNC.md)。

### 修改设置与暂存

- 未保存的仓库、Token 和开关输入仅在当前浏览器会话暂存，关闭弹窗后重新打开可继续填写；暂存不启用同步。
- 点击“保存设置”才应用配置；已配置 Token 不回显，修改设置时 Token 留空保留原值。
- “放弃暂存”清除未保存输入；浏览器重启或扩展重新加载、更新也会清除暂存。
- “移除设置”删除本地同步配置与专用 Token，不删除 GitHub 仓库中的已有文件。
- 填写时可点击右上角“在新标签页中打开”，继续在保持打开的设置页操作。

### 同步失败与限制

自动模式会在相关保存后及定期检查时尝试同步，浏览器休眠可能延后执行；也可点击“立即同步”。关闭“自动同步”仍可手动同步，但需保持“启用同步”。

断网不影响本地保存。失败后查看状态提示，修正网络、仓库或 Token 后重试；自动模式也会在后续检查重试。编辑冲突保留副本，不静默覆盖其中一方。

超出同步容量会失败并保留本地数据，容量与调度限制见[同步技术规格](./specs/SPEC_GITHUB_SYNC.md)。删除普通内容或移入私密库不会清除已有 Git 历史。

## 后台 AI 整理

Provider 指你选择的 AI 服务。开启后，符合规则的已保存通用 Prompt 与 Skill 会发给该服务，用于补标题和归类；私密内容、草稿、AIGC 与指令不发送。

1. 在“设置 → 隐私锁”设置密码，用于加密保存 API Key。
2. 打开“设置 → 后台 AI 整理 → Provider”，点击“+ 添加 Provider”。
3. 选择服务类型，填写显示名称、Base URL、Model ID、API Key 和隐私锁密码。预设提供地址与模型示例，请填写自己有权使用的模型；自定义服务需使用 OpenAI 兼容接口。
4. 点击“保存 Provider”，按提示授予该服务地址的访问权限。
5. 在 Provider 列表中点击“设为当前”，再点击“测试”；按提示输入隐私锁密码解锁后台 AI，确认连接结果。
6. 返回设置，在“后台 AI 整理”中勾选“开启”。

开启后处理之后新保存或正文实质修改的内容，不自动回扫旧库。处理已有内容时，点击“整理现有内容 → 整理”；阈值在“整理阈值”中调整，分类方案在“分类结构建议”中查看和应用。完整规则见[当前产品规格](./specs/SPEC.md)。

API Key 加密保存在本地，本次浏览器会话解锁后供后台使用。**重设隐私锁会清空 Provider 配置，需要重新配置 API Key**，但不会删除资产或私密内容。

## 网页就地取用

1. 打开“设置 → 就地取用”，勾选“开启”。
2. 点击“站点”，启用需要使用的网站，并按提示授权。常见 AI 网站也可通过弹窗顶部提示启用。
3. 回到已启用网站的输入框，输入 `//` 或按快捷键打开面板，选择资产后按 Enter 插入，按 Esc 关闭。

默认快捷键为 `Alt+Shift+F`，实际绑定以 `edge://extensions/shortcuts`（Chrome 为 `chrome://extensions/shortcuts`）为准；冲突时可在那里修改。“// 触发符”可单独关闭。

聊天页面板取用通用 Prompt 与 Skill，支持的绘画页取用普通 AIGC；私密内容与指令不出现在面板中。插入只按你的确认操作进行，不替你发送消息。

Skill 的复制与就地取用会在主文件前加一行引导语，收藏的原始文件不变，具体文本见[产品规格](./specs/SPEC.md)。

## Skill 投递到 Agent

1. 在“设置 → Agent 目录”找到目标 Agent，点击“选择目录”，按界面提示选择并授权目录。
2. 打开已收藏 Skill 的详情；新标签页阅读界面可通过“编辑 Skill”或“管理 Skill”进入。
3. 在“投递到 Agent”中点击目标 Agent 的“投递”，已有本扩展副本可点击“更新投递”。

绑定目录只记住位置，不自动投递。权限失效时点击“允许访问”重新授权；“解除绑定”不会替你撤回已写入的 Skill。

“撤回”只删除能确认属于该条资产的 FutureContext 投递副本，库内收藏保留。外来的同名 Skill 显示为“目录里已有”，不会被撤回；版本不同时可明确选择“更新本地”，这会覆盖外来同名 Skill，但不会把它变成可撤回的副本。

## 备份与恢复

- 在“设置 → 导出全部数据”点击“导出”；若私密库未解锁，按提示前往解锁后继续。备份是包含普通与私密内容的明文 JSON，请妥善存放。
- 在“设置 → 导入备份”点击“导入”并选择 JSON。导入合并新内容，不覆盖或删除已有条目；导入的私密内容仍需解锁后查看。

同步不包含私密库和全部本地配置，不能代替完整资产备份。

## Prompt 占位符（0.4.0）

收藏带变量的通用或 AIGC Prompt 时，在编辑页开启“占位符模式”，正文使用双花括号，例如 `一只 {{动物}}，位于 {{场景}}`。编辑页会列出识别出的字段；默认不开启，也不会自动修改已有收藏。

打开模板或点击列表“使用”，直接在正文里填写。重复出现的同名变量自动同步，可切到“渲染结果”检查完整文字，再点击“复制结果”。所有变量均需填写；编辑页的“试用模板”可以试用当前草稿，再通过“继续编辑”返回。

在已授权网页的取用面板中选择模板，同样先填写，再点击“插入结果”或按 Ctrl / ⌘ + Enter。Esc 或“取消”保留原输入；不会自动发送。私密 AIGC 仅在解锁后的扩展工作区使用，永不进入网页面板。

本次填写关闭后不保留，收藏仍是原始模板。模板模式随备份、普通库同步与私密迁移保留；使用 GitHub 同步时请将所有设备的扩展升级至 0.4.0，旧版本会拒绝含新字段的同步文件。
