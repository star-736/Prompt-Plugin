# FutureContext 项目术语

FutureContext 是个人本地 AI 资产库，用于收集、组织并复用 Skill、通用 Prompt、AIGC Prompt 与指令。

本文只定义术语。操作步骤见[配置指南](./CONFIGURATION.md)，功能和交互规则见[当前产品规格](./specs/SPEC.md)，设计理由见[文档导航](./README.md)。

## 资产与资料库

**FutureContext**：产品名称，强调为未来的 AI 创作和工作积累可复用资产。
_Avoid_：Prompt Vault、FuturePrompt

**AI 资产**：用户保存并复用的工作材料，涵盖通用 Prompt、Skill、AIGC Prompt 和指令；内容类别与是否私密是不同概念。
_Avoid_：第三类资产（指私密库）

**通用 Prompt**：可反复使用的泛用文本提示词，可有标题与一级分类。
_Avoid_：参数化 Prompt

**AIGC Prompt**：以自由文本为主体的创作提示词，可位于普通库或私密库；早期文档也称“自由 Prompt”。
_Avoid_：正负提示词参数表

**指令**：用于终端、CLI、AI Agent、浏览器或快捷键速查的可复用文字，以正文为标识。
_Avoid_：第四类 Prompt、脚本资产

**单文件 Skill**：只有一个包含名称与描述的 `SKILL.md` 文件的 Skill。
_Avoid_：包式 Skill

**包式 Skill**：由 `SKILL.md` 和脚本、模板、参考资料或资源组成的完整 Skill 文件包。
_Avoid_：截取主文件充当完整包

**普通库**：当前浏览器配置文件内无需解锁即可浏览的资产区域。
_Avoid_：受保护库、云端库

**私密库**：需在当前工作区会话中解锁后才能浏览的 AIGC 区域，是可见性边界。
_Avoid_：独立资产类型、强加密保险箱

**可恢复的隐私锁**：防止随手查看私密库的本地访问锁，忘记密码后可重设并保留内容。
_Avoid_：不可恢复加密

**库优先创建**：先进入目标库再创建资产的交互规则；私密 AIGC 从已解锁私密库发起创建。
_Avoid_：新建时勾选私密

**一级分类**：通用 Prompt、Skill 与指令分别维护的单层分类。
_Avoid_：子分类树、无限文件夹

**编辑草稿**：尚未正式保存、可恢复的本地编辑内容。
_Avoid_：输入即发布、关闭弹窗即丢失输入

## 工作区与取用

**工具栏入口**：点击扩展图标打开的完整工作区，可在弹窗或新标签页中使用。
_Avoid_：浏览器侧边栏

**弹窗会话**：从工具栏弹窗打开到关闭的一段使用时间，区别于后台 AI 使用的浏览器会话。
_Avoid_：长期登录态

**显式复制**：用户明确点击后将资产的取用文本写入剪贴板。
_Avoid_：选中即复制

**就地取用**：用户在启用站点的当前输入框中选择并确认后，插入资产的取用文本。
_Avoid_：自动注入、自动发送

**取用面板**：网页输入框旁用于搜索和选择普通资产的入口，不承担资产管理。
_Avoid_：页内管理页、浮动侧边栏

**启用站点**：用户明确启用并授权就地取用的网站。
_Avoid_：全站默认注入

**就地保存**：通过右键菜单把用户主动选中的文字保存为通用 Prompt。
_Avoid_：自动采集、整段对话抓取

**取用次数**：显式复制或就地取用累计次数，用于本地常用排序。
_Avoid_：遥测、统计上报

**常用排序**：按最近编辑、最近取用或最常取用排列普通资产。
_Avoid_：智能排序、手动拖拽排序

**置顶**：用户为普通资产指定的固定排序优先级。
_Avoid_：收藏夹、星标分组

**永久删除**：用户确认后删除库内资产，不提供回收站恢复。
_Avoid_：自动撤回所有外部副本

## AI 与外部服务

**后台 AI 整理**：通过用户配置的 Provider 为通用 Prompt 补标题、为通用 Prompt 与 Skill 归类；早期文档称“二期 LLM 整理”。
_Avoid_：私密库后台整理、平台内置 AI 账号

**AI 整理记录**：AI 操作及变更映射的概念；完整历史调整与一键撤销仍属后续方向。
_Avoid_：当前已有整库回滚

**Provider 配置**：用户保存并选择的 AI 服务、模型和凭据设置。
_Avoid_：多个后台 Provider 并行运行

**AI 密钥保险盒**：以隐私锁密码保护本地 Provider 凭据、按浏览器会话解锁的能力。
_Avoid_：第二套密码、永久明文凭据

**GitHub Skill 收集**：用户主动将公开 GitHub 上的具体 Skill 及相关文件保存到本地。
_Avoid_：安装并运行 Skill、自动扫描仓库

**GitHub 私有仓库同步**：用户启用后，在本地普通库与自己的已有个人私有仓库之间合并资产与分类。
_Avoid_：同步私密库、完整备份上传

**完整备份**：可导入的单个 JSON 资产备份，包含普通与私密内容；早期文档称“一期本地备份”。
_Avoid_：加密备份、同步快照

## Agent 投递

**Agent 目录绑定**：用户选择并授权一个 Agent 的本地目录，供后续按条投递。
_Avoid_：自动发现主目录、全库自动投递

**投递到 Agent**：用户明确把已收藏 Skill 写到授权目录，形成属于 FutureContext 的可撤回副本。
_Avoid_：同步到 Agent、自动安装

**目录里已有**：授权目录中存在同名 Skill，但不是该资产的可撤回投递副本。
_Avoid_：已投递、已同步

**版本不一致**：外来同名 Skill 的主文件与库内收藏不同。
_Avoid_：自动同步本地版本

**撤回投递**：删除能确认属于该资产的 FutureContext 投递副本，保留库内收藏与外来副本。
_Avoid_：卸载 Skill、回滚资料库
