# 将可恢复的隐私锁作为库边界，而不是新建表单的选项

FutureContext 会要求用户先解锁并进入私密库，再新建私密 AIGC Prompt。这样能让隐私状态在浏览、创建和迁移时保持清晰；普通库与私密库之间的移动是明确、可确认的数据迁移操作。首次进入私密库时，用户设置至少 6 位并重复确认的密码，不额外强制复杂度。忘记密码时可由同一入口重设，且不会删除私密内容。重设前会明确说明重设后可直接进入私密库并设置新密码，确认后不要求旧密码。这个设计的目标是阻止他人随手打开扩展查看资料，而不是提供不可恢复的强加密保险箱，因此能操作浏览器配置文件的人也能重设后查看私密库。解锁只在当前弹窗会话有效：普通库始终可直接查看，而每次新打开弹窗、再次进入私密库时都需要输入密码。
