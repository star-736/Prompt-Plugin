# 将公开 GitHub Skill 保存为带精确 Commit 的完整本地包

GitHub 收集只从用户当前打开的具体 `SKILL.md` 页面发起。FutureContext 使用该页的仓库、路径和精确 Commit 保存同目录的完整递归文件树到 IndexedDB，包含脚本、参考资料和资源，但从不执行。保存后可在详情页手动按来源仓库默认分支检查更新；有变化时直接更新包内容，同时保留条目的分类与本地管理信息。

每个包限制为 10 MB、单文件限制为 5 MB；任一超限就整体拒绝，避免半个 Skill 被伪装为成功保存。没有把 ZIP、本地文件、私有仓库、自动更新或第三方平台上传加入本期，因为它们会扩张权限、数据来源和执行边界。
