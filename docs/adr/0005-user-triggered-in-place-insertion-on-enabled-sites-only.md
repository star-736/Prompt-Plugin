# 就地取用由用户触发、页面代码只在启用站点加载

一期把“显式复制、不自动注入”定为原则，但只靠弹窗内的复制按钮，取用路径与笔记软件摩擦相当，使用频率上不去。三期加入取用面板：用户在输入框中输入 `//` 或按快捷键后，自己搜索、选择并按 Enter 才写入内容。我们把它与“自动注入”区分开：前者每次写入都有用户的明确确认动作，后者是未经确认就填入或改写页面。这样既补上取用路径，又不推翻一期原则。

页面代码只在用户逐站启用后注册，站点权限走可选主机权限、停用即撤销；脚本只读取当前焦点输入框中的文字以识别触发符，不读取页面其他内容。不采用“默认对所有 AI 网站生效”的做法，即便它对新用户更顺手，因为那会让扩展在商店里申请对所有网站的读取权限，与本地优先、最小权限的定位相悖。

触发符选用 `//` 而非单个 `/`，因为 ChatGPT、Claude 等站点已把单斜杠用作自带菜单，叠加会造成冲突和误触。
