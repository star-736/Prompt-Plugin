# 终端指令作为第四类普通库资产，不塞进通用 Prompt

用户需要收集 CLI / AI Agent 命令，但这不是 Prompt：没有标题语义，不该发给 LLM，也不该出现在聊天页取用面板。把它做成通用 Prompt 的一个分类会污染搜索和后台整理；做成私密库条目则过度隔离。因此新增独立类型 `command`（标签「终端指令」）：内容优先、无标题、只在普通库、有自己的一级分类，沿用复制 / 置顶 / 草稿 / 备份，且不抬数据库版本号。页签加在最后并保持与其它页签相同的字号和间距——720px 弹窗装得下四个平级页签，不必折行或缩小。

## 后续调整：统一为“指令”

页签和编辑页名称扩展为“指令”，收纳终端 / CLI / AI Agent 命令以及 `chrome://restart` 等浏览器指令。分类仍由用户自行维护，例如“终端指令”“浏览器指令”；不预置分类或重分已有条目。内部类型与分类区域继续使用 `command`，现有条目、草稿和备份无需迁移。保存、搜索和复制沿用原有行为。
