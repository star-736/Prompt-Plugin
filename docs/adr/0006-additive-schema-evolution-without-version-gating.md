# 数据模式只做增量演进，版本号不作为清空门禁

FutureContext 的全部资产存放在 `chrome.storage.local` 的单个 JSON 对象里，读取时以“展开旧对象、补默认值”的方式归一化。这让新代码能读旧数据，也让旧代码在回退时原样保留不认识的字段。因此从三期起，每一期新增能力只允许在既有结构上增加可选字段，不删除、不重命名、不改变已有字段的语义；废弃字段留在数据中不再读取（一期 AIGC 的标题与分类即为先例）。

数据库与备份的版本号只在结构真正不兼容时才提升，并且提升的那一期必须提供把旧版本转换为新版本的迁移函数。归一化函数遇到比自身更新的版本号时，不得把库当作空库返回：二期以前的实现会这样做，而后台 AI 的状态写回会在几秒内把空库覆盖到真实数据上，导致代码回退时数据被清空。正确做法是原样保留数据、禁止写入，并提示用户升级扩展。

大块二进制或超过文本规模的内容（如包式 Skill 的文件树）继续走 IndexedDB，只在主 JSON 中保留引用，以避开 `chrome.storage.local` 的 10 MB 配额。
