# FutureContext 隐私政策

生效日期：2026 年 8 月 15 日

FutureContext 是一个本地优先的浏览器扩展，用于保存、分类、编辑和复制通用 Prompt、单文件 `SKILL.md` 和 AIGC Prompt。

## 我们处理的数据

FutureContext 只会在你的当前浏览器配置文件中保存你主动输入或导入的内容，包括 Prompt、Skill 文本、标题、分类、编辑草稿、私密库内容，以及用于私密库访问锁的本地验证信息。

当你选择导出时，扩展会在你的设备上生成一份 JSON 备份文件。备份文件可能包含私密库内容。

## 数据如何使用和保存

这些数据仅用于在扩展中显示、搜索、分类、编辑、复制、导入和导出你的内容。数据保存在浏览器的本地扩展存储中；FutureContext 没有账号系统、服务器、云同步、分析工具、广告 SDK 或 AI 模型调用。

除非你主动通过浏览器的导出功能将备份保存到设备，FutureContext 不会把你的内容发送给开发者、第三方服务或其他用户。我们不会出售、出租或共享你的内容。

## 私密库说明

私密库是一个可恢复的本地访问锁，用于避免他人随手打开 FutureContext 时看到你的 AIGC 内容。它不是不可恢复的强加密保险箱。能够访问你的浏览器配置文件或本机账户的人，可能仍可重设访问锁或读取本地浏览器数据。重设访问锁不会删除私密内容。

私密库内容在锁定时不会显示标题或数量。请不要把导出的 JSON 备份发送给不受信任的人，并自行妥善保管备份文件。

## 你的控制权

你可以在 FutureContext 中编辑或永久删除任意保存的内容。删除分类时，其中条目会被移至“未分类”；删除条目后无法在扩展内恢复。你也可以在浏览器扩展管理页移除 FutureContext，或通过浏览器的数据管理功能清除其本地数据。

## 政策更新与联系

如 FutureContext 的数据处理方式发生变化，本政策会随版本更新。若对本政策有疑问，请通过商店页面所列的支持联系方式联系开发者。
