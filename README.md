# Prompt Vault for Edge

一个离线、密码保护的 Edge / Chrome 提示词保险箱。它用于把灵感、图片提示词或视频提示词先安全地收起来，之后解锁、搜索并复制到任何生图或视频工具中使用。

## 已实现的 MVP

- 初次打开创建主密码；密码不会被保存。
- 所有提示词标题、正文、标签和时间戳都会在写入 `chrome.storage.local` 前用 AES-GCM 加密。
- 密钥从主密码和随机盐通过 PBKDF2-SHA-256 派生；每次加密使用新的随机 IV。
- 每次打开扩展弹窗都必须重新输入密码；关闭弹窗立即丢弃内存中的解锁状态。
- 新建、编辑、删除、搜索和一键复制提示词。
- 不需要账号、云同步、网页读取或网络权限。

## 安装到 Edge

1. 运行 `npm test`，确认本地检查通过。
2. 打开 `edge://extensions`，开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本项目根目录。
4. 将扩展固定到工具栏，点击图标后创建主密码。

Chrome 同样可用：在 `chrome://extensions` 使用相同步骤。

## 安全边界

这是为“浏览器资料不能直接被看到”设计的本地保险箱，并不是针对已解锁电脑上的恶意软件、键盘记录器或浏览器开发者工具的防护。请使用强且唯一的主密码；忘记主密码无法恢复资料，只能清空保险箱重新开始。
